### 📐 Engineering Principles

1. **Deterministic & Lightweight**: Zero unnecessary heavy ML/runtime dependencies in critical latency paths. Fast, thread-safe heuristics.
2. **Defensive by Design**: Strict input validation, zero unhandled promises, constant-time token comparison, SSRF protection, and entropy-based secret scrubbing.
3. **Resilient Under Load**: Mid-stream failover, exponential backoff with jitter, parallel speculative hedging, and graceful service degradation.
